# 1.アプリ名
・ドーナツガチャ

ドーナツをランダムで選択するアプリです
。引きたい個数を１～１０個の中から選択すると、ランダムにドーナツが選ばれ、商品名と税込価格が表示されます。

## アプリの機能

- ガチャを引く個数を1〜10個から選択
- ボタンを押すとガチャ演出を表示
- ドーナツをランダムに抽選
- 商品名と税込価格を表示
- もう一度引くボタンからトップ画面に戻る

## 開発環境の構築

### 1. リポジトリをクローン

```bash
git clone <GitHubリポジトリのURL>
cd donut_gacha
```

### 2. Gemのインストール

```bash
bundle install
```

### 3. データベースの作成・初期化

```bash
bin/rails db:prepare
```

### 4. ドーナツデータの登録

```bash
bin/rails db:seed
```

### 5. サーバーの起動

```bash
bin/rails server
```

ブラウザで以下にアクセスしてください。

http://localhost:3000

## テスト

以下のコマンドでテストを実行できます。

```bash
bin/rails test
```

## ドーナツデータについて

ドーナツの商品情報は `db/seeds.rb` で管理しています。

初期データを登録する場合は、次のコマンドを実行してください。

```bash
bin/rails db:seed
```

※ `db/seeds.rb` は既存のドーナツデータを削除してから登録する構成のため、再実行すると登録済みデータが入れ替わります。
