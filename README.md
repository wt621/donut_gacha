# ドーナツガチャ

ドーナツをランダムに選ぶことができるアプリです。

引きたい個数を1〜10個から選択すると、抽選演出の後にランダムでドーナツが選ばれ、商品名・カテゴリー・税込価格が表示されます。

## アプリの機能

- ガチャを引く個数を1〜10個から選択
- ボタンを押すとガチャ演出を表示
- ドーナツをランダムに抽選
- 商品名・税込価格を表示
- もう一度引くボタンからトップ画面に戻る

## 開発環境の構築

### 1. リポジトリをクローン

```bash
git clone <GitHubリポジトリのURL>
cd donut_gacha
```

### 2. Gemのインストール

```bash
bundle install
```

### 3. サーバーの起動

```bash
bin/rails server
```

ブラウザで以下にアクセスしてください。

http://localhost:3000

## テスト

以下のコマンドでテストを実行できます。

```bash
bin/rails test
```

## ドーナツデータについて

ドーナツの商品情報は `app/models/donut.rb` で管理しています。

データベースは使用せず、アプリケーション内に定義した商品情報からランダムに抽選します。
